Social Justice Math Lessons
Interactive high school math lessons built on real public data. Students check the numbers in the original source, build their own tables and charts, do the math, and reflect on what the data means. Math is the subject; social justice is the theme.

Lessons
#	Lesson	Math
1	Which place has the most homelessness?	Rates per 10,000 people; comparing counts and rates
Each lesson folder has:

interactive/index.html: the student activity (one file, runs in any browser)
lesson-plan.md: standards, timing, answer key and discussion notes
slides.html: slides to launch and close the class
sources.md: every number with its source, link and a search phrase to find it
Using a lesson
Open interactive/index.html in a web browser. There is no login, and nothing a student types is sent anywhere. Students save their work as a PDF to hand in.

Canvas: don't paste the file into a Canvas Page or upload it to Canvas Files. Canvas blocks the JavaScript the lesson needs. Host it on the web (for example GitHub Pages) and link to it from Canvas, ideally opening in a new tab.

Data
All figures come from public government sources such as HUD, the U.S. Census Bureau and the King County Regional Homelessness Authority. Each was checked against its source; see each lesson's sources.md for links and the date checked.
